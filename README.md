Project Title: Tree Progress Tracker

Purpose:
The purpose of this project is to build a web-based interface that visually tracks the growth and progress of planted trees. It aims to promote environmental awareness while demonstrating structured web development.

Tools Used:
HTML
CSS

Implementation & Outcome:
I implemented the core structure using HTML to display tree data and growth milestones. The outcome is a functional, organized web page that successfully showcases my foundational front-end development skills and serves as my first step toward full-stack development.
